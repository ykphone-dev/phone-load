모두 총액 견적입니다. 가격만이 아니라 인원·작업범위·추가금 조건·A/S를 같은 기준으로 비교하세요.

같은 기준으로 비교

"A 38만 / B 42만 / C 46만"만 보여주면 결국 최저가 플랫폼이 됩니다. 그래서 인원·범위·추가금 조건·A/S를 같은 표에 놓습니다. 업체끼리는 서로 가격을 볼 수 없어요.
