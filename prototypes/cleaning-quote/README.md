# 청소견적 비교 MVP 프로토타입

> 우리 집 청소비, 얼마가 적당할까요?

주소와 평수만 입력하면 여러 청소업체가 **동일한 요청서**를 보고 **총액 견적**을 제시하고,
소비자가 가격뿐 아니라 인원·작업범위·추가금 조건·A/S를 **같은 기준으로 비교**하는 서비스의
화면 프로토타입입니다. **단일 HTML 파일**이며, 이 저장소의 Next.js 앱과는 연결되어 있지 않습니다.
검토와 논의용으로 별도 브랜치에 올려 두었습니다.

- 원본 아티팩트: https://claude.ai/artifact/HptLDZfuoQbBchngQZfQQH
- 파일: `index.html` (외부 의존성은 Google Fonts뿐, 서버 없이 동작)

## 보는 방법

1. `index.html`을 내려받아 브라우저에서 엽니다. 모바일 화면(최대 480px) 기준으로 설계되어 있습니다.
2. 또는 브라우저에서 바로 미리보기:
   https://htmlpreview.github.io/?https://github.com/ykphone-dev/phone-load/blob/prototype/cleaning-quote/prototypes/cleaning-quote/index.html

## 화면 구성

- **소비자**: 청소 종류(입주·이사 집중) → 주소 → 면적(평/㎡) → 청소 예정일 → 현재 상태 → 방/화장실/베란다 → 추가 요청 → 사진(선택)
  → 견적요청서 미리보기(업체에 보이는 그대로, 전화번호 미포함) → 업체 5곳 요청 → 견적 3건 비교(카드 + 동일 기준 비교표)
  → 견적 상세·견적확정 조건(포함/제외/추가금 발생 가능 조건, 업체 신뢰도) → 업체 선택·예약 → 완료 + 이사견적 크로스셀
- **업체**: 무료 입점(사업자·지역·청소 종류·보험) → 견적 요청함(총액 입력, 인원·시간, 제공 서비스, 추가금 조건 필수, A/S) → 예약 관리·클레임·정산
- **운영자**: 핵심 KPI 6개(견적요청 CPA, 6시간 내 3견적 수신율, 견적→선택률, 선택→작업률, 현장 추가금 발생률, 클레임/재작업률),
  지역별 수요·공급, 청소 종류별 요청, 제휴업체 없는 요청 수동 대응, 운영 큐, 업체 추천 기준(만족도 30·재작업률 25·정확도 20·응답 15·작업량 10),
  수익모델 A/B/C 계산기(성사 수수료 · 업체 구독 · 혼합)

## 동작 규칙 (프로토타입 기준)

- 견적은 항상 **기본 청소비 + 추가작업 + 기타비용 = 총 견적**으로만 받습니다.
- 업체는 견적을 낼 때 **추가금 발생 가능 조건**을 반드시 고르거나 "추가금 없음(전액 확정)"을 선택해야 합니다.
- 추천순은 가격과 광고비를 넣지 않고 서비스 품질 데이터로만 계산합니다. 가격은 비교표에서 직접 비교합니다.
- 주소의 시/도에 제휴업체가 없으면(예: 세종·제주) 운영자 수동 대응 흐름으로 분기합니다.
- 업체 화면에서 견적을 보내면 소비자 비교 화면에 "내 업체 (방금 입력)"으로 즉시 추가됩니다.

## 참고

- 화면 안의 업체, 금액, 건수, KPI는 모두 예시 데이터입니다. 평당 단가와 추가비용은 데모용 가정값입니다.
- 실제 서비스로 만들 때는 이 저장소의 `src/` 구조(Next.js + Supabase)에 맞춰 다시 구현해야 합니다.
