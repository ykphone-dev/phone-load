# 전화 안 오는 이사견적 MVP 프로토타입

이사 정보를 한 번만 입력하면 여러 이사업체의 **최종 견적**을 비교하고, 업체 전화가 쏟아지지 않도록
연락처는 고객이 선택한 업체에만 공개하는 서비스의 화면 프로토타입입니다.
Claude 아티팩트로 만든 **단일 HTML 파일**이며, 이 저장소의 Next.js 앱과는 연결되어 있지 않습니다.
검토와 논의용으로 별도 브랜치에 올려 두었습니다.

- 원본 아티팩트: https://claude.ai/artifact/MEwg1AKDA9u3DGzSCdSRw7
- 파일: `index.html` (외부 의존성은 Google Fonts뿐, 서버 없이 동작)

## 보는 방법

1. `index.html`을 내려받아 브라우저에서 엽니다. 모바일 화면 기준으로 설계되어 있습니다.
2. 또는 브라우저에서 바로 미리보기:
   https://htmlpreview.github.io/?https://github.com/ykphone-dev/phone-load/blob/prototype/moving-quote/prototypes/moving-quote/index.html

## 화면 구성

- **소비자**: 현재 집 → 도착지 → 이사 종류 → 짐은 하나하나 적지 않고 사진·간단 선택 → 미리 알려줄 것(선택) → 견적 알림 연락처
  → 여러 업체 최종 견적 비교 → 선택 결과 → 이사 다음에 필요한 것(입주청소 등 크로스셀)
- **업체**: 새로운 이사 견적 요청 확인 → 견적 입력
- **운영자**: 이번 주 견적요청 현황, 지역별 요청·업체, 수익모델 테스트, 클레임 큐

## 참고

- 화면 안의 업체, 금액, 건수는 모두 예시 데이터입니다.
- 실제 서비스로 만들 때는 이 저장소의 `src/` 구조(Next.js + Supabase)에 맞춰 다시 구현해야 합니다.
